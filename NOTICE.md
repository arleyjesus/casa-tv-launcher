# Credits and third-party names

Casa Aura TV, previously Casa TV Launcher, is maintained by Arley Vera (arleyjesus).

The application was developed with AI coding assistance. The bundled desert wallpaper was generated with AI image assistance for this project. It is included with the project's MIT license; no third-party photography was copied into the application.

The runtime loads icons and names from applications already installed on the user's device. Netflix, YouTube, Prime Video, Disney+, HBO Max/Max, Spotify, Android, Google TV, TCL and Projectivy names or marks remain associated with their respective owners. No third-party APK, proprietary launcher source or manufacturer firmware is distributed here.

Projectivy and community Android TV experiments informed testing and compatibility research, but Casa is a separate application and does not depend on Projectivy. The repository does not include community debloat scripts.

Uses Android framework APIs and the JDK/Android SDK build tools. These tools are installed separately and are not bundled.

The 0.4 control center uses original Canvas icons and native Android views. Apple/tvOS design guidance is a visual reference; no Apple interface assets or source code are included, and there is no Apple affiliation. Device-specific TCL Guard research is credited in docs/TCL-C645-GUARD.es.md; no Guard Manager application code or binary is bundled.

The 0.6 fjord and forest landscapes were generated for Casa with the built-in image generator. All three bundled landscapes are original project assets under MIT. Their generation prompts are recorded in docs/AMBIENT-ART-PROMPTS.md.

Online catalogs contain links and credits for third-party media. Their licenses are stated per item; they do not acquire the MIT license of the application code. NASA/USGS resources and the CC0 WordPress photo are not bundled in the APK. The Big Buck Bunny test clip is credited to Blender Foundation under CC BY 3.0, served by Test Videos. See docs/AMBIENTE-ONLINE.es.md and the source links in the catalog.
