# Casa Aura TV 0.10.0 · Ambiente online

Ambiente estrena un panel con pestañas para colecciones, aspecto, vídeo y catálogo. Se pueden descargar fotos por colección, guardar favoritas y usar orden aleatorio. La caché reutiliza archivos sin cambios y mantiene un límite de 64 MiB. El catálogo inicial incorpora fuentes de hasta 4K sin añadir esas imágenes al APK.

Se añaden brillo, contraste y saturación para las imágenes de Ambiente, junto con desplazamiento y zoom suave. Los ajustes del televisor y de otras aplicaciones conservan su funcionamiento.

El vídeo MP4 se reproduce desde una URL HTTPS, siempre silenciado, con calidad máxima, Solo Wi-Fi y límites de datos y tiempo por sesión. El inicio automático viene apagado. Ante un error vuelve a imágenes; al salir cierra el reproductor. HLS, DASH y YouTube siguen pendientes de integración.

El repositorio incorpora un historial visual de versiones con capturas conservadas por etiqueta. El README mantiene las imágenes actuales y enlaza esa evolución. También se simplificó la redacción del apartado Rendimiento.

La nueva identidad continúa en estudio: esta versión conserva el nombre Casa Aura TV y el mismo paquete para actualizar sin perder configuración.
